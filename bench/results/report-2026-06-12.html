What actually fixed it — found by the benchmark, in order

  1. Clicks-by-NAME protocol. Model answers ["8","Multiply","="] — symbols it knows — instead of volatile element numbers it must look up. Harness resolves names → indices. The single biggest lever.
  2. Symbol aliases. Fixture said "×", real Calculator says "Multiply". Alias table bridges both; calc went 0-clicks-forever → 100%.
  3. Honesty guard. A plan naming a button that isn't on screen is refused — "cannot: × is not on screen" — never acted on. Lying structurally blocked where the harness can see it.
  4. Dedup fix. Digest was deleting 4 of 5 "Learn more" links as "duplicates" — disambiguation was literally impossible. Caught only because the e2e bench failed while the paper gate passed.
  5. Navigation cut + load-wait. A link click ends the batch (remaining clicks belong to a dead page — model once hit "Back" via a stale index) and the loop waits for the new page to actually load before re-planning.
